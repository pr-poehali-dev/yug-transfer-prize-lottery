# Перенос «Базы знаний» на свой сервер (VPS)

Инструкция для администратора сервера. Рассчитана на Ubuntu 22.04/24.04, займёт 2–4 часа.

## Что переносится

| Что | Откуда взять |
|---|---|
| Код сайта и серверной части | этот репозиторий (папки `src/`, `backend/`, `server/`, `deploy/`) |
| База данных: 57 таблиц, ~128 тыс. записей (28 тыс. карточек, подписки, посты, аккаунты сканера) | файл `baza-XXXX.sql.gz` (см. п. 0) |
| Фото карточек (~21,5 тыс. файлов, ~300 МБ) | скачиваются скриптом `server/restore_files.py` по ссылкам из базы |
| Ключи, токены, пароли | секреты проекта на poehali.dev — переписать вручную в `.env` |

## 0. ДО удаления проекта на poehali.dev — обязательно

1. **Скачайте копию базы** по ссылке, которую выдал разработчик (`.../export/baza-XXXX.sql.gz`), и сохраните в 2 местах.
   Копия сделана на момент выгрузки. Если после этого были изменения — попросите выгрузить заново.
2. **Скачайте код**: в редакторе «Скачать → Скачать код» (или через GitHub).
3. **Перепишите значения всех секретов** (Ядро → Секреты) — список в `.env.example`. После удаления проекта их не восстановить.
   Особенно важны: токены ботов, ключи ЮKassa, `TG_API_ID`/`TG_API_HASH`, прокси.
4. **Перенесите фото (п. 5) до удаления проекта** — после удаления ссылки на старые фото перестанут работать.

## 1. Подготовка сервера

```bash
apt update && apt install -y nginx postgresql python3-venv python3-pip git curl certbot python3-certbot-nginx
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs
mkdir -p /opt/baza && cd /opt/baza
# скопируйте сюда код проекта (git clone ... . или распакуйте архив)
```

## 2. База данных

```bash
sudo -u postgres psql -c "CREATE USER baza WITH PASSWORD 'ПРИДУМАЙТЕ_ПАРОЛЬ';"
sudo -u postgres psql -c "CREATE DATABASE baza OWNER baza;"
gunzip -c baza-XXXX.sql.gz | psql "postgresql://baza:ПАРОЛЬ@127.0.0.1:5432/baza" -v ON_ERROR_STOP=1
```

Проверка: `psql ... -c "SELECT count(*) FROM t_p67171637_yug_transfer_prize_l.check_lists"` → около 28 тыс.

Схема называется `t_p67171637_yug_transfer_prize_l` — так и оставьте, код на неё рассчитан.

## 3. Настройки

```bash
cp .env.example .env
nano .env   # впишите значения всех ключей и адреса своего домена
```

## 4. Серверная часть

```bash
python3 -m venv venv
venv/bin/pip install -r server/requirements.txt
cp deploy/baza-api.service /etc/systemd/system/
chown -R www-data:www-data /opt/baza
systemctl daemon-reload && systemctl enable --now baza-api
curl http://127.0.0.1:8000/api/health   # должен вернуть список функций
```

Каждая папка `backend/<имя>` доступна по адресу `https://ваш-домен/api/<имя>`.

## 5. Фото

Вариант А — фото лежат на самом сервере (проще):
```bash
venv/bin/python server/restore_files.py download   # скачает все фото в FILES_DIR
```
Для новых фото нужно S3-хранилище. Самый простой путь — MinIO на этом же сервере
(бакет `files` с публичным чтением, nginx уже проксирует `/files/` на него), затем:
```bash
venv/bin/python server/restore_files.py upload     # зальёт скачанные фото в S3
venv/bin/python server/restore_files.py relink     # заменит старые ссылки в базе на FILES_PUBLIC_URL
```
Вариант Б — облачное S3 (Яндекс Облако, Selectel): укажите `S3_ENDPOINT`, ключи и `FILES_PUBLIC_URL`, затем те же `download → upload → relink`.

## 6. Сайт

```bash
npm install
VITE_API_BASE=https://ваш-домен/api npm run build      # результат в папке dist/
cp deploy/nginx.conf /etc/nginx/sites-available/baza   # поправьте домен
ln -s /etc/nginx/sites-available/baza /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d baza-info.online -d www.baza-info.online
```

В `index.html` есть служебные скрипты платформы `cdn.poehali.dev/intertnal/...` — после переноса их можно удалить.

## 7. Расписание (сканер, автопубликация постов, ежедневные задачи)

```bash
crontab -u www-data deploy/crontab.txt
```

## 8. Переключить ботов и оплату на новый адрес

Telegram-боты (адрес в браузере, замените домен):
```
https://ваш-домен/api/kb-bot?action=set_webhook&url=https://ваш-домен/api/kb-bot
https://ваш-домен/api/site-bot?action=set_webhook&url=https://ваш-домен/api/site-bot
https://ваш-домен/api/info-bot?action=set_webhook&url=https://ваш-домен/api/info-bot
```
Бот MAX:
```
https://ваш-домен/api/max-bot?action=subscribe&url=https://ваш-домен/api/max-bot
```
ЮKassa: в личном кабинете → Интеграция → HTTP-уведомления → укажите `https://ваш-домен/api/kb-bot`.

## 9. Проверка

- Вход в админку на `https://ваш-домен/` по логину/паролю из `.env` (`POSTS_LOGIN`/`POSTS_PASSWORD`).
- Поиск человека в базе, открытие карточки с фото.
- Команда `/start` в боте базы знаний.
- Раздел «Глобальное сканирование» — запуск и рост счётчиков.
